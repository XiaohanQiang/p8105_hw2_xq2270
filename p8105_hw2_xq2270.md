# Problem 1

``` r
subway_df = 
  read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |>
  janitor::clean_names() |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    route1:route11,
    entry,
    vending,
    entrance_type,
    ada
  ) |>
  mutate(
    entry = case_match(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    )
  )
```

The cleaned subway dataset contains 1868 observations and 19 variables.
It includes information on subway line and station name, station
latitude and longitude, routes served, entrance type, entry and vending
status, and ADA compliance. During data cleaning, I standardized
variable names, retained only the variables relevant to the analysis,
and converted the `entry` variable from character values (“YES” and
“NO”) to a logical variable. The dataset is not fully tidy because the
routes served by each station are stored across multiple columns
(`route1` through `route11`) rather than in separate route number and
route name variables.

``` r
mci_baseline = 
  read_csv(
    "data/data_mci/MCI_baseline.csv",
    skip = 1
  ) |>
  janitor::clean_names() |>
  mutate(
    age_at_onset = na_if(age_at_onset, "."),
    age_at_onset = as.numeric(age_at_onset),
    sex = case_match(
      sex,
      0 ~ "Female",
      1 ~ "Male"
    ),
    apoe4 = case_match(
      apoe4,
      0 ~ "Non-carrier",
      1 ~ "Carrier"
    )
  ) |>
  filter(
    is.na(age_at_onset) | age_at_onset > current_age
  )
```

``` r
baseline_summary = 
  mci_baseline |>
  summarise(
    recruited = n(),
    developed_mci = sum(!is.na(age_at_onset)),
    mean_baseline_age = mean(current_age)
  )

female_apoe4_prop = 
  mci_baseline |>
  filter(sex == "Female") |>
  summarise(
    proportion = mean(apoe4 == "Carrier")
  ) |>
  pull(proportion)
```

The cleaned baseline dataset contains 479 participants after excluding
individuals who had MCI at baseline. The dataset includes participant
ID, baseline age, sex, years of education, APOE4 carrier status, and age
at MCI onset. Sex and APOE4 status were converted from numeric
indicators to descriptive categorical variables, and missing MCI onset
ages were coded as `NA`.

Among the 479 participants, 93 developed MCI during the follow-up
period. The average age at baseline was 65 years. Among women in the
study, 30% were APOE4 carriers.

``` r
mci_amyloid = 
  read_csv(
    "data/data_mci/mci_amyloid.csv",
    skip = 1
  ) |>
  janitor::clean_names() |>
  pivot_longer(
    cols = baseline:time_8,
    names_to = "time",
    values_to = "amyloid"
  ) |>
  mutate(
    time = case_match(
      time,
      "baseline" ~ 0,
      "time_2" ~ 2,
      "time_4" ~ 4,
      "time_6" ~ 6,
      "time_8" ~ 8
    ),
    amyloid = as.numeric(amyloid)
  ) |>
  rename(
    id = study_id
  )
```

The amyloid dataset was reshaped from wide to long format, with
measurement times coded as 0, 2, 4, 6, and 8 years. Amyloid measurements
were converted to numeric values. There were 8 participants found only
in the cleaned baseline dataset and 16 found only in the amyloid
dataset.

The final analytic dataset contains 471 participants, 2355 observations,
and 8 variables. Each row represents a participant at a scheduled
measurement time, with baseline demographic characteristics and amyloid
biomarker measurements. The dataset was exported as
`data/mci_complete.csv`.
